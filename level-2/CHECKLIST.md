# Level 2 work

What Level 2 adds to this folder, and which module asks for each:

- `compare.md`, Module 2.3. Doing the Git workflow by hand versus directing a coding
  agent, and one thing the agent could have done better that you changed. If you found
  nothing to correct, show the diff you read and what you checked. The template is
  already here. Fill it in.
- `scope.md`, Module 2.4. Written before you build, naming what finished looks like.
- `test-report.md`, Module 2.4. What you tested against that definition and what
  happened, naming anything that did not work. Every test passing is fine if the report
  shows the tests.
