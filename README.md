# AI Foundations, portfolio repository

This folder becomes your repository in Module 2.2. Your name goes on every commit, and the
dated history stays yours after the program ends.

Follow the commands in Module 2.2 exactly. This file does not repeat them, so you have
one set of instructions to follow.

## What is in the kit

| Item | What it is for |
| --- | --- |
| `notes.md` | A short notes file. Module 2.2 has you edit one line of it on two branches to practise resolving a conflict. |
| `level-1/` | Your Level 1 work. Module 2.2 has you copy in your Module 1.1 to 1.4 work before your first commit, and your Module 1.5 work later on a branch. `level-1/README.md` lists it. |
| `level-2/` | `compare.md` is the template for Module 2.3. `CHECKLIST.md` lists what Level 2 adds here. |
| `level-3/` | `CHECKLIST.md` lists what Level 3 adds here. You write the `README.md` and `commercial-use-note.md` yourself in Module 3.3. |
| `.gitignore` | Tells Git which files never to record, such as `.env` files that hold secrets. Leave it in place. |

Keep the repository **public** when you submit. The automatic checks read it through
GitHub, and so will an employer.

## After the program

Keep adding to it after the program ends, including work from an internship.
